# 追加キャラクター詳細

世界観との整合性を優先すると、3人とも「物語の真相を説明するためだけの人物」ではなく、**それぞれ自分の立場では常識的に行動しているのに、旅を通じて価値観が揺らぐ人物**にすると組み込みやすいです。

以下の3人を提案します。

## 1人目：七神教会側の仲間  
### セレナ・アルヴェール
**性別：女性 / 年齢：19歳前後 / 職業：七神教会の若い神官**

主人公と最も早い段階で同行する仲間です。

セレナは七神教会の地方聖堂で育った若い神官で、七神への信仰心が非常に強い人物です。ただし盲目的な狂信者ではなく、**「七神の教えとは人々を救うためにある」**と本気で信じています。

地方の教会で、貧しい人への食事の配給や負傷者の治療などを実際に行ってきたため、主人公から見ても「七神教会＝人々を助ける善良な組織」という印象を強める存在になります。

### 性格

普段は穏やかで面倒見がよく、パーティでは常識人。

しかし意外に頑固です。

特に宗教に関しては、

「教会が間違っている可能性」

をなかなか受け入れられません。

主人公が神代の記録から、

「七神は世界を創造したわけではないのでは？」

と疑い始めても、

「解釈の違いかもしれません」

「その記録自体が正しい保証はありません」

と反論します。

この反応は教会を守りたいからではなく、**自分がこれまで救われ、そして他人を救ってきた価値観そのものが崩れるのが怖い**からです。

### 加入理由

主人公が勇者として旅立つ際、七神教会から、

**「勇者を支援する神官」**

として同行を命じられます。

つまり最初から主人公と同じ陣営です。

主人公とセレナは、

「魔王を倒して世界を救う」

という共通認識から旅を始めます。

### 戦闘スタイル

典型的な**回復・支援型神官**。

- 回復魔法
- 状態異常回復
- 防御強化
- 蘇生系の補助
- 七神への祈りによる特殊支援

などを担当します。

ただし主人公の再挑戦だけは、彼女の魔法では再現できません。

これが序盤から、

「主人公の復活は七神の加護なのか？」

という疑問につながります。

### 主人公の再挑戦への反応

最初は、

**「勇者に七神の加護が与えられている」**

と解釈します。

ところが神代遺跡で古代装置が主人公を「参加者」と認識したことで、徐々に疑問を持ち始めます。

それでもしばらくは、

「試練機構そのものが七神の加護なのでは」

と考えようとします。

### 物語上の最大の葛藤

七神教会の過激派が主人公を排除しようとした時です。

セレナにとって、

**教会は自分の家そのもの**

です。

しかし、その教会の一部が歴史を改変して魔王の力を狙っている。

同時に、一般の司祭たちは何も知らず、本当に人々を救おうとしている。

だから彼女は、

「教会は全部間違っていた」

とはならない。

最終的には、

**「七神を信じること」と「七神教会の言うことをすべて信じること」は違う**

という答えにたどり着きます。

これは主人公の「自分で判断する」という成長とも重なります。

### プレイヤーから好かれやすい部分

普段はしっかり者なのに、マサには妙に弱い。

主人公：

「そこ踏むな」

セレナ：

「ただの床ですよ？」

主人公：

「いいから」

セレナ：

「……前にも私、ここで死にました？」

主人公：

「…………」

みたいな掛け合いができます。

### 恋愛要素

**恋愛対象にかなり向いています。**

旅立ちから一緒なので、最も王道のヒロインポジションになります。

恋愛ルートでは、主人公から再挑戦の真実を聞いた後、

「私が死んだところも見たことがあるんですか？」

というイベントを置けます。

主人公が肯定すると、以降セレナは主人公の「死んでも戻れる」という能力を便利なものとして扱わなくなります。

最終決戦前、再挑戦機能が失われた時の感情的な役割も非常に強いです。

# 2人目：魔王側の事情に接点を持つ仲間
### カイル・レヴァント
**性別：男性 / 年齢：22歳前後 / 職業：傭兵兼魔物狩り**

人間社会で育った人物ですが、幼少期を魔王領との国境付近で過ごしています。

そのため、

**人類と魔王軍の双方の被害を実際に見てきた**

人物です。

魔王軍によって村を襲われた経験もあるため、魔王軍を善とは考えていません。

ただし同時に、人間側の兵士が「魔族だから」という理由だけで非戦闘員まで敵視していた光景も知っています。

そのため、

**「魔王軍は敵だが、教会が言うこと全部が正しいとも限らない」**

というスタンスを持っています。

### 性格

口が悪く、かなり現実主義者。

主人公とセレナが、

「勇者として世界を救う」

と話している横で、

「世界なんかより、今日の飯の心配しろ」

と言うタイプ。

しかし他人を見捨てることができません。

危険な状況では、

「助ける義理なんてねえ」

と言いながら真っ先に助けに行きます。

つまり、

**口では冷たいが行動は優しい。**

### 加入理由

主人公たちが魔王軍の活動地域を通過する際、現地案内人として雇われます。

最初は一時的なNPC同行の予定。

しかし主人公たちがマサに巻き込まれ、カイル自身も巻き込まれたことで共闘。

その後、主人公たちだけでは危なっかしいと判断し、そのまま同行します。

本人は、

「金が出るなら付き合う」

と言いますが、本当の理由はもう少し後で分かります。

### 魔王側との接点

カイルは国境地帯で長く暮らしているため、

**魔王軍の行動には不自然な部分がある**

ことを知っています。

例えば、

「魔王軍が本気で世界征服したいなら、なんで戦略的価値のない場所ばかり襲う？」

「魔王本人を見たって奴が一人もいないのはなぜだ？」

といった疑問です。

彼自身も答えは知らない。

だから「魔王は善人」と最初から知っているわけではありません。

この点が重要です。

### 戦闘スタイル

**前衛物理アタッカー兼タンク。**

- 剣
- 大剣
- 斧
- 挑発
- カウンター
- 魔物特効

など。

マサ攻略では、

「罠を見抜く」

より、

**多少の罠なら力ずくで突破する**

タイプ。

主人公：

「そこ爆発するぞ」

カイル：

「どの程度だ？」

主人公：

「死ぬ程度」

カイル：

「先に言え！」

という担当です。

### 主人公の再挑戦への反応

三人の中で一番怖がります。

主人公が、

「死んでも戻るから試してみる」

と言うと、

**「お前、自分が死ぬことに慣れてないか？」**

と最初に指摘する人物です。

主人公の再挑戦能力を、

「便利な能力」

としてではなく、

**主人公の精神を削る危険なもの**

として見る。

ここはかなり大事です。

### 物語上の役割

魔王軍との戦争が、

**単純な善悪ではない**

と主人公へ最初に意識させる人物。

ただし魔王軍そのものが実際に人類へ攻撃しているため、

「魔王軍だって普通に敵だ」

とも言います。

魔王本人が魔王軍へ世界征服を命じていなかったと判明した際には、

「やっぱりな」

ではなく、

**「いや、そこまでは予想してねえよ」**

という反応にした方が自然です。

### 個人的なドラマ

過去に魔王軍の襲撃で家族の一部を失っている設定にします。

そのため、魔王の真実を知っても、

**「じゃあ魔王軍に殺された奴らはどうなる？」**

という問題を突きつけます。

魔王本人に罪がなかったとしても、魔王の名のもとに実際の犠牲者が生まれている。

この人物がいることで、

**「魔王が悪くなかったから全部めでたし」**

という単純な展開を防げます。

### 恋愛要素

主人公の性別を固定しない場合、恋愛対象にしても成立します。

ただ、恋愛対象にしない場合でも、主人公との強い友情を描きやすい人物です。

特に最終決戦前、

「今回は死んだら戻れない」

と判明した時、

普段軽口ばかりのカイルが、

「戻ってこないなら、俺が死ぬ前提の作戦も禁止だからな」

と釘を刺す。

こういうキャラクターにできます。

# 3人目：マサ・神代研究の仲間
### リリア・クローデン
**性別：女性 / 年齢：20歳前後 / 職業：神代史・マサ研究者 / 魔法使い**

教国や七神教会とは独立した立場で神代遺跡を研究する若い研究者。

年齢の割に神代文字の読解能力が非常に高く、マサ研究に関しては専門家クラス。

ただし、

**頭は非常にいいのに、危険に対する感覚がかなりおかしい。**

典型的な研究馬鹿です。

### 性格

好奇心が異常に強い。

未知のマサを見つけると、

「触ってみましょう」

と言い出す。

主人公：

「爆発するかもしれない」

リリア：

「だから触るんです」

主人公：

「嫌だよ」

という人物。

一方、普段は冷静で論理的。

魔王の古代記録が見つかっても、

「これだけでは歴史改変の証拠になりません」

と客観的に判断します。

三人の中で最も、

**証拠を重視する人物**

です。

### 加入理由

主人公が初めて本格的な神代遺跡へ入った際に出会います。

彼女はすでに単独で遺跡を調査していた。

ところが主人公が古代装置へ近づいた瞬間、

今まで一度も起動しなかった装置が作動する。

装置には主人公を、

**「参加者」**

として認識する反応が現れる。

リリアは主人公へ興味を持ち、

「あなたと一緒にいれば、今まで開かなかった遺跡を調べられる」

という理由で同行を申し出ます。

かなり打算的な加入です。

### 戦闘スタイル

**高火力魔法・解析型。**

- 属性魔法
- 敵弱点解析
- マサ解析
- 敵行動予測
- 魔法による範囲攻撃

など。

知識神が魔法を司る設定とも自然につながります。

ただし、リリア本人と知識神との特別な関係は設定しません。

六柱の匂わせ人物とは別枠です。

### 主人公の再挑戦への反応

最初は完全に研究対象として興奮します。

「死亡時に記憶だけが保持されている？」

「身体状態だけでなく周囲も復元される？」

「それは蘇生ではなく――」

と主人公を質問攻めにする。

しかし、旅を続けて主人公が何度も死んでいることを理解すると変わります。

主人公：

「一回死んで確認する」

リリア：

「ダメです」

主人公：

「前はやれって言ってなかった？」

リリア：

「……あの頃は、あなたが死ぬということを数字として考えていました」

という変化を作れます。

これが彼女の人間的成長です。

### 物語上の役割

最も重要なのは、

**真相へのナビゲーターであって、真相を最初から知っている人物ではない**

ことです。

彼女も、

- 七神が世界を創造した
- 魔王は人類の敵

という一般的歴史教育を受けています。

ただし研究者なので、

**証拠が出れば自分の常識を捨てられる。**

そのため、

主人公・セレナ・カイルの意見がぶつかった時の整理役にもなります。

### 七神の真相との関係

神代記録から、

**七神が世界を「創造した」のではなく「整備した」**

ことを最初に論理的に立証する人物にできます。

さらに、

- 試練機構
- 参加者
- 超越者
- 死神と時空神による復元システム

を主人公たちが理解する際の中心人物になります。

### 恋愛要素

こちらも非常に相性がいいです。

セレナが王道ヒロインなら、リリアは、

**最初は主人公を研究対象として見ていた人物が、徐々に「失いたくない人」として見るようになる**

タイプです。

好感度イベントでは、

「あなたが死ぬところを私は覚えていない。でも、あなたは覚えている。それって不公平ですよね」

というテーマも使えます。

真ラスボス前には、

「あなたが戻れないなら、私はもうあなたを観察対象とは呼べません」

といった変化も自然です。

# 4人パーティとしての関係

この3人にすると、かなり会話を作りやすいです。

**主人公**  
最初は王道勇者。死と再挑戦を経験しながら、自分で判断する人物へ成長。

**セレナ**  
「信じる」という立場。

**カイル**  
「疑う」という立場。

**リリア**  
「確かめる」という立場。

この三角形がかなり強いです。

例えば古代記録を見つけた場合、

セレナ  
「教会の教えと違います……」

カイル  
「だから教会なんて信用するなって」

リリア  
「どちらも早計です。まず年代測定します」

主人公  
「……調べよう」

となる。

つまり仲間三人が、そのまま主人公の判断材料になります。

---

さらに性格面でも、

**セレナ：穏やかな常識人だが頑固**  
**カイル：口が悪い現実主義者だが優しい**  
**リリア：冷静な天才だが研究になると暴走する**

と明確に差別化できます。

バカゲー部分ではリリアが暴走し、カイルがツッコミ、セレナまで巻き込まれ、主人公が「前の周回で全員死んだからやめろ」と止める、といった掛け合いもできます。

そしてシリアスになると、それぞれがきちんと物語の核心へ関われます。

この三人なら、**王道RPGの仲間らしさ、キャラクター人気を狙える個性、恋愛要素、確定済みストーリーへの組み込みやすさ**の4点をかなり両立できると思います。

# 恋愛対象・友情関係の確定事項

了解です。これで主要4人パーティの人物設定は確定として扱います。

主人公との恋愛対象は**セレナ・アルヴェール**と**リリア・クローデン**の2人。**カイル・レヴァント**は恋愛対象から外し、主人公とは強い友情関係を築く立場に固定します。

その他についても、先ほど提案した年齢・性格・職業・加入理由・戦闘スタイル・主人公の再挑戦への反応・物語上の葛藤・各キャラクターの成長軸を、そのまま確定設定として扱います。今後はこの前提から逸脱しないように進めます。
