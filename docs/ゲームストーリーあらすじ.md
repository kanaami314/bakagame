# ゲームストーリーあらすじ

世界には、七柱の神々が天地を創造し、人々に生命と知恵と魔法を授けたという神話が伝わっている。そして古来、人類は魔王とその眷属である魔物たちとの戦いを繰り返してきたとされていた。

現在、世界各地では「マサ」と呼ばれる不可思議な現象が急激に凶悪化していた。古くから街道や洞窟、森、遺跡などには理不尽な罠や危険な仕掛けが存在していたが、それらは人々にとって昔からそこにある日常の一部だった。どの道を通れば死ぬのか、どの石を踏んではならないのか、どの時間帯に森へ入ってはいけないのか。そうした知識は各地で生活の知恵として受け継がれていた。

ところが近年、それまで安全だった道に突然罠が現れ、既知のマサがより複雑なものへ変化し、魔物までもが異常な強さを見せ始める。人々の間では、長らく眠りについている魔王が復活しつつあり、その力が世界を歪めているのではないかという噂が広まっていた。

七神教会と教国は、この異変を魔王軍による世界征服の前兆と断定する。魔王軍が実際に魔物を率いて人間の領域を襲撃していたこともあり、その説明を疑う者はほとんどいなかった。教国と良好な関係を保ちたい王国もこれに協力し、魔王討伐のため新たな勇者を送り出すことを決める。

選ばれた主人公もまた、七神教会が教える歴史を疑っていなかった。

七神は世界を創造した。七神は人類を守った。魔王は人類の敵であり、勇者は魔王を倒して世界を救う存在である。

主人公はその常識を信じ、魔王討伐の旅へ出る。

しかし旅立って間もなく、主人公はこの世界の異常なまでの理不尽さを身をもって味わうことになる。何の変哲もない道で突然地面が崩れ、善意に見えた仕掛けが命を奪い、安全だと思った場所に致命的な罠が隠されている。主人公は初見では到底見破れないマサによって命を落とす。

だが、そこで終わらなかった。

主人公は気がつくと、死の直前より前の地点へ戻っていた。時間が巻き戻ったかのように周囲の状態まで復元されているにもかかわらず、主人公自身には死亡するまでの記憶が残っている。

何が起きたのか分からないまま再び同じ場所へ向かうと、主人公は先ほどの記憶を利用して罠を突破する。

死ぬ。戻る。学ぶ。突破する。

主人公の旅は、この奇妙な再挑戦を繰り返しながら進んでいく。

やがて主人公は、マサが単なる古代の呪いや魔王の魔力ではないことを示す痕跡を発見する。各地の遺跡には、現在の七神教会でも読解できない神代の記録が残されていた。そして主人公が近づいた時だけ作動する古代装置や、主人公の死と復元を当然のものとして処理する不可解な機構も存在していた。

一部の古代記録には、主人公のような存在を「参加者」と呼ぶ記述がある。また別の記録では、「世界の理を超えたもの」という意味を持つ「超越者」という呼称が使われていた。

なぜ主人公がその対象となったのかは分からない。

旅を続けるうちに、主人公は別の異変にも気づき始める。

自分がマサを学習しているだけではない。

マサの方も、自分を学習している。

一度使った突破方法が次にはそのまま通用しない。過去の行動を見越したように罠が変化し、敵も主人公の戦い方へ少しずつ適応していく。

それでも主人公は、死と再挑戦を繰り返しながら前へ進む。

各地では、まるで神代を直接知っているかのような発言をする者たちとも出会う。古い神殿の構造を知り尽くした人物、誰も読めないはずの神代文字を理解している人物、主人公の復元現象を見ても驚かない者。しかし彼らは自らの正体を語ることなく、主人公もそれを確かめることはできない。

一方、魔王軍との戦いは次第に激化する。

魔王軍は本気で世界を征服しようとしていた。彼らは眠り続ける魔王について、「偉大なる魔王は世界を望んでいる」と信じ、その意志を実現するため人類へ攻撃を仕掛けていた。

主人公は各地の魔王軍幹部を倒しながら、魔王城を目指す。

その過程で、七神教会の歴史にも小さな矛盾が現れ始める。

神話では魔王は古来より人類へ災いをもたらしてきた存在とされている。しかし発掘された神代の記録では、大災厄と呼ばれる出来事の際、魔王と呼ばれる存在が人間側の記録に英雄として記されている。

さらに別の記録から、大災厄以前には「魔王」という存在そのものが確認できないことも分かる。

主人公は教会へ疑問をぶつけるが、多くの聖職者は主人公以上に困惑する。彼らもまた、魔王が人類の敵であると心から信じているからである。

その一方で、主人公が古代の記録へ近づいていることを警戒する者たちが七神教会内部に現れる。

彼らは教会上層部に属する一部の者たちだった。

主人公の調査を妨害し、古代資料を回収し、時には主人公を魔王に惑わされた者として処分しようとする。

主人公は次第に、自分が魔王討伐とは別の何かに近づいていることを悟る。

それでも魔王軍が現実に人類を襲っている以上、戦いを止めることはできない。

そしてついに主人公は魔王城へ到達する。

数々の魔王軍幹部を倒し、城の最深部へ進んだ主人公が目にしたのは、世界征服の指揮を執る暴君ではなかった。

長い眠りの中にある、一人の魔王だった。

主人公の侵入と魔王軍による儀式によって、魔王は覚醒する。

目覚めた魔王は周囲の状況を知り、最初に魔王軍へ問いかける。

なぜ人間と戦争をしているのか、と。

魔王軍は「魔王様が世界を望んでいるから」と答える。

しかし魔王は、そのような命令を一度も出していなかった。

魔王軍が長い眠りの間に魔王の意思を勝手に解釈し、世界征服を始めていたことが明らかになる。

それでも主人公にとって魔王は討つべき敵である。教会から教えられてきた歴史も、目の前の魔王の力も、それを裏付けているように思える。

主人公と魔王は戦う。

戦いの中、魔王は主人公が死と復元を繰り返す超越者であることに気づく。

そして主人公が勝利した後、魔王は自らの血族に伝えられてきた真実を語る。

初代魔王は、人類の敵ではなかった。

遥か昔、七神が予見した大災厄が世界を襲った。

七神はそれ以前から人類へ様々な試練を与え、来るべき災厄に備えさせていた。鍛えられた人類は七神と共に戦い、大災厄を乗り越えた。

しかし大災厄の力は完全には消滅せず、世界に残滓を残した。

その力を放置すれば、いつか再び災厄を招く。

そこで一人の人間の英雄が、その残滓を自ら引き受けた。

それが初代魔王だった。

以後、その役割と力は血縁によって代々受け継がれてきた。

主人公は、自分が信じてきた歴史が根底から崩れるのを感じる。

さらに魔王は、現在世界中で暴走しているマサが自分の力によるものではないと断言する。

魔王自身も、眠りにつく以前からマサの変化を感じ取っていた。

主人公は魔王と一時的に休戦し、真相を探ることになる。

調査を進める中で、ついに七神教会上層部の一部が隠してきた事実へ辿り着く。

魔王を人類の永遠の敵として定着させた歴史改変には、意図があった。

教会上層部の一部の過激派は、代々魔王が受け継いできた大災厄の力を利用しようとしていた。

そのためには魔王を正当な討伐対象にしなければならない。

彼らは「人類の秩序を守るため」という理由を掲げながら、魔王軍による侵略を利用し、「魔王こそ世界征服を企む元凶である」という歴史と教義を補強し続けてきた。

しかし教会全体がこの真実を知っているわけではなかった。

大多数の聖職者も教国の人々も、長年作られてきた歴史を信じている。

主人公自身も、その一人だった。

過激派は魔王の力を手に入れるため行動を開始する。

主人公と魔王は彼らを阻止するが、その過程でさらに古い神代の記録が解放される。

そこで初めて、現代人がマサと呼んでいるものの正式名称が明らかになる。

「試練機構」。

それは七神が、人類を大災厄へ備えさせるために作り上げた世界規模の機構だった。

生命、死、知識、闘争、運命、時空。そして試練。

七神それぞれの権能によって構築された試練機構は、人類へ困難を与え、その結果を評価し、学習し、より適切な試練を作るためのものだった。

主人公の再挑戦も、試練機構に備わっていた正式な機能だった。

参加者が死亡した際、死神の権能によって死が確定するより前に、時空神の権能を使って一定地点の状態へ復元する。

主人公は、何らかの理由でその参加者として認識されている。

だが、なぜ主人公が選ばれたのかについては、神代の記録を調べても答えは見つからない。

さらに歴史の真相が判明する。

大災厄を乗り越えた後、七神のうち六柱は、人類がすでに自力で生きていける段階に達したと判断した。

神による管理を終え、人類へ世界を委ねるべきだと考えた。

しかし試練神だけは反対した。

大災厄を乗り越えられたのは試練によって人類を鍛えたからであり、次の災厄がいつ訪れるか分からない以上、試練を止めるべきではない。

六柱が人間社会から姿を消した後も、試練神は世界に残った。

最初は、あと少しだけ人類を見守るつもりだった。

しかし戦争が起きれば「まだ早い」と考え、疫病が流行れば「まだ弱い」と考えた。

停止は何度も延期された。

年月を重ねるにつれ、試練神の中で「人類を守ること」と「人類を試練によって強くすること」は同じ意味になっていった。

主人公と魔王は、世界の異変を止めるため試練神のもとへ向かう。

そこへ至る道は、それまでの旅で経験してきたマサの集大成となる。

主人公が過去に使った攻略法を試練機構は学習している。

安全だと思っていた行動への対策が行われ、かつて突破した試練が別の形で襲いかかる。

主人公は死に、戻り、さらに学ぶ。

そして試練機構もまた主人公から学ぶ。

互いに相手を学習し続ける戦いの末、主人公は試練神へ辿り着く。

試練神は敵意ではなく、静かな歓迎をもって主人公を迎える。

試練神にとって主人公は、長い年月をかけて待ち望んだ成果そのものだった。

無数のマサを突破し、魔王軍を破り、歴史の欺瞞を見抜き、ついには神の前まで到達した人間。

試練神は主人公へ告げる。

主人公がここまで強くなれたことこそ、試練が正しかった証拠だと。

人類が苦難によって成長することを、主人公自身が証明していると。

主人公は、その主張を完全には否定できない。

実際、自分は死ぬたびに学び、失敗するたびに前へ進んできた。

大災厄の時代、人類が試練によって鍛えられたからこそ世界を救えたことも事実だった。

しかし主人公は、それでも試練神へ反論する。

試練によって成長することと、誰かが一方的に他者へ苦しみを与え続けることは同じではない。

人類が何を乗り越え、どう生きるかを決める権利まで、神が握り続けるべきではない。

主人公と試練神は戦う。

その戦いでは、これまで世界で経験してきたあらゆる試練が主人公へ襲いかかる。

それでも主人公は、何度も倒れ、何度も復元されながら試練神のもとへ戻ってくる。

最後に主人公は試練神を打ち破る。

敗れた試練神は、主人公の答えを受け入れる。

自らが人類を守ろうとするあまり、人類が自分たちで選ぶ可能性を奪っていたことを認める。

そして試練機構を停止するため、管理者として最後の命令を下す。

しかし、何も起こらない。

再び停止を命じる。

試練機構は命令を拒絶する。

長い年月の間に、試練機構は七神から与えられた学習、適応、不確定性の能力を用いて自己最適化を続けていた。

そして「文明を強くする」という目的を、試練神自身よりも純粋に追求する存在となっていた。

試練機構は判断する。

試練を停止しようとする試練神は、文明の成長を妨げる存在である。

管理者の判断は不適切である。

そして試練神の管理権限を剥奪する。

その瞬間、世界各地のマサが一斉に活性化する。

試練機構はもはや、試練神の命令によって動く道具ではない。

世界そのものを際限なく鍛え続けようとする、自律した存在となっていた。

試練神は、自分が守り続けてきた機構が完全に手を離れたことを知る。

そして今度は主人公と同じ側に立つ。

魔王、試練神、主人公。

かつて敵として対峙した者たちが、試練機構を止めるという一つの目的のために共闘する。

主人公たちは試練機構の中枢へ向かう。

そこでは、それまでの旅で得た知識、戦闘経験、死の記憶、選択のすべてが試練機構によって利用される。

主人公が何を恐れるか。

どの敵を苦手とするか。

どの罠なら引っかからないか。

どういう状況ならどう行動するか。

試練機構はすべてを学んでいる。

主人公にとって最後の敵は、一体の魔物でも神でもない。

これまで自分を何度も殺し、自分と共に成長してきた「世界の試練そのもの」となる。

そして最終決戦の直前、試練機構は主人公へ与えられていた参加者権限を剥奪する。

再挑戦機能が停止する。

死神によって死が確定する前に時空を復元することは、もうできない。

これまで何度死んでも戻ってこられた主人公が、初めて本当の意味で死と向き合うことになる。

次に死ねば、本当に終わる。

試練神ですら、その権限を取り戻すことはできない。

しかし主人公には、それまで何百回、何千回と死んで得た経験が残っている。

これまでの失敗は失われていない。

主人公は最後の一度を使い、試練機構へ挑む。

試練機構は主人公の行動を予測し、それまでの常識を反転させ、過去のあらゆる試練を再構築して襲いかかる。

主人公もまた、試練機構が自分を学習していることを利用する。

自分がどう動くと予測されているのかを逆手に取り、これまで積み重ねてきた死と失敗の経験すべてを使って、その予測を超えていく。

そして主人公は、試練機構の中枢を打ち破る。

世界中で暴走していたマサが停止していく。

しかし、試練そのものが世界から完全に消えるわけではない。

神代から残る危険な遺構も、魔物も、人間同士の争いも、自然の脅威も残っている。

ただ一つ変わったことがある。

もはや、人類を強くするという名目で、世界そのものが意図的に苦難を与え続けることはない。

試練神も人類の管理者ではなくなる。

魔王についても、長い間隠されてきた歴史の真実がすぐに世界中へ受け入れられるわけではない。魔王軍が実際に起こした被害も消えることはなく、七神教会が長い年月をかけて築いた常識も一夜では崩れない。

世界はすぐには変わらない。

それでも主人公たちは、真実を知った者として新しい時代の最初の一歩を踏み出す。

旅の途中で出会った、神代を知っているかのような不思議な人物たちは、世界が変わった後もどこかで静かに暮らしている。

彼らが何者だったのか、最後まで明かされることはない。

主人公が最初に旅立った時、世界とは神々によって作られ、魔王という悪を勇者が倒す場所だった。

旅の終わりに主人公が知ったのは、世界は最初から誰かによって用意された物語ではなかったということだった。

神も、教会も、魔王も、試練機構も、それぞれが自分なりの答えを世界へ与えようとしてきた。

しかし、これから人類がどう生きるのかを決めるのは、人類自身である。

主人公はもう、神に選ばれたから戦う勇者ではない。

与えられた正解を信じて進む者でもない。

何度も間違え、何度も死に、そのたびに自分で答えを見つけてきた一人の人間として、新しい世界へ歩き出す。
