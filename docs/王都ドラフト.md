## 2. 住民（27人）

マサ（初見殺し）の噂は仕様どおり**一切入れていない**。
話題は勇者・魔王軍・王都の暮らし・教会に限っている。

### 北 ── 王城前

| 人物 | 台詞の要点 |
|---|---|
| 王城の衛兵 | 任は下された。城へ戻る用はない。達者でな |
| 王城の衛兵 | この門はもう開かぬ。発つのなら南の城門から |
| 門番長 | 城下は好きに見て回れ。支度が済んだら南の城門へ |

### 西 ── 聖堂（オルディナ教国 王国支部）

| 人物 | 台詞の要点 |
|---|---|
| 聖堂の神官 | ここは教国の王国支部。本国の大聖堂とは比ぶべくもない |
| 老いた司祭 | 七神は世界を創り、人を守り、去られた。そう教わり、そう教えてきた |
| 参拝者 | 息子が兵に取られた。無事を祈りに来た |
| 参拝帰りの女 | 教会の炊き出しには助けられた。あれだけは本物 |

老いた司祭の台詞は、七神が世界を「創った」という偽りの歴史を、
善良な人物が心から信じている様子として置いた。

### 東 ── 商業区

| 人物 | 台詞の要点 |
|---|---|
| 道具屋（店主） | 旅の支度なら任せとくれ |
| 武具屋（店主） | 命を預ける物だ、よく選べ |
| 買い物客 | 武具屋の親父は口が悪いが品は確か |
| 行商人 | 荷が思うように運べず、王都の品は値上がり |
| 鍛冶の弟子 | 剣は重さでなく振れる速さで選べ |
| 屋台の女 | 勇者様、代金はいりません |

### 中央広場

| 人物 | 台詞の要点 |
|---|---|
| こども | ほんとに勇者なの? 剣見せて |
| こども | 大きくなったら騎士になる |

| 噴水の老人 | 昔も勇者は幾人か発った。戻った者はまだ一人もいない |
| 王都の女 | 噴水は王都の自慢。水がずっと絶えない |
