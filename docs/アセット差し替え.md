# アセット差し替え手順

現在ゲーム内で使われているドット絵は**すべて仮アセット**である。
`scripts/art/TileArt.gd` の中に文字列パターンとして書かれており、コードから生成している。

本番の絵ができたら、**決められた場所へPNGを置くだけで置き換わる。**
コードの修正もシーンの編集も不要。

---

## 仕組み

絵を要求されると、まず差し替え用のPNGを探し、見つかればそれを使う。
無ければ仮アセットを生成して使う。

置いたPNGを消せば、仮アセットへ自動的に戻る。

---

## 置き場所

### タイル・物体

```
res://assets/tiles/<名前>.png
```

| 名前 | 内容 |
|---|---|
| `grass` | 草地 |
| `path` | 土の道 |
| `tree` | 木（通行不可） |
| `house` | 家の壁 |
| `house_door` | 家の扉 |
| `roof` | 屋根 |
| `floor` | 遺跡の石床 |
| `wall_stone` | 遺跡の石壁 |
| `pillar` | 柱 |
| `castle_floor` | 城の大理石の床 |
| `castle_wall` | 城壁 |
| `carpet` | 赤絨毯 |
| `throne` | 王座 |
| `chest` | 宝箱 |
| `sign` | 立て札・石碑 |

**サイズは 16×16 ピクセル。** 1マスがこの大きさで敷き詰められる。

### 人物

```
res://assets/sprites/<look_id>_<向き>.png
```

向きは `down` `up` `left` `right` の4種類。
つまり1人につき4枚必要になる（例：`priest_down.png` `priest_up.png` …）。

| look_id | 人物 |
|---|---|
| `hero` | 主人公 |
| `priest` | セレナ（神官） |
| `king` | オルヴァン王 |
| `guard` | 衛兵 |
| `official` | 文官 |
| `maid` | 侍女 |
| `elder` | 村長 |
| `villager` | 村人 |
| `merchant` | 道具屋 |
| `innkeeper` | 宿屋 |

**幅は 16 ピクセル。高さは 16 以上なら任意。**
16 より背が高い絵を置いた場合、足元がマスの底に揃うよう自動で位置を調整する。
頭身の高いキャラクターへ差し替えても、立ち位置がずれない。

透過部分は透明（アルファ 0）にしておくこと。

## Godot 側の設定

ドット絵をぼかさずに表示するため、読み込み設定を確認する。

プロジェクト全体の既定値は `project.godot` で
`textures/canvas_textures/default_texture_filter=0`（最近傍）にしてあるため、
通常はPNGを置くだけでよい。

個別に設定を変えたい場合は、Godotエディタでファイルを選び
「インポート」タブから調整する。

---

## 新しい look_id や タイル名を増やす場合

`scripts/art/TileArt.gd` に、

- タイルなら `_build()` の `match` と、対応する仮アセットの文字列パターン
- 人物なら `LOOKS` への追加

を行う。仮アセットを用意しない場合でも、PNGさえ置けば表示はされる
（仮アセットが無い名前を要求すると、目立つマゼンタ色で表示され、
指定間違いに気づけるようにしてある）。

---

## 確認方法

マップ全体と絵の一覧をPNGへ書き出せる。ゲームを起動せずに見た目を確認できる。

```
godot --headless --path . --script res://tools/render_preview.gd
```

書き出し先は実行後に表示される。
